# Employee Management System

## Overview
The Employee Management System is a web application designed to streamline the administrative processes of managing employee information. This system allows the organization to keep track of employee details, their roles, and manage them effectively.

## Features
- **Add New Employee**: Allows users to add new employee records.
- **Update Employee Information**: Users can update existing employee details.
- **Delete Employee Records**: The system supports the deletion of employee records when necessary.
- **Search Employees**: Users can search for employees based on various criteria.
- **Role Management**: Administrators can manage roles and permissions within the system.
- **Dashboard**: Provides a summary of employees and related statistics.

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript, React
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Version Control**: Git

## Installation
1. Clone the repository: 
   ```bash
   git clone https://github.com/dimitrisabra/employee-management-system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd employee-management-system
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

## Usage
- Access the application through your web browser at `http://localhost:3000` after starting the server.
- Follow the on-screen instructions to manage employee records.
